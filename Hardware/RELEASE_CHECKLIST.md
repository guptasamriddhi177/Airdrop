# Manufacturing Release Checklist

- [ ] Electrical schematic completed at pin level.
- [ ] Exact BOM part numbers and approved alternates.
- [ ] Production connector series selected.
- [ ] Power tree and thermal calculations reviewed.
- [ ] Antenna keep-out verified against Espressif documentation.
- [ ] Footprints cross-checked with manufacturer land patterns.
- [ ] ERC passed.
- [ ] PCB fully routed and DRC passed.
- [ ] 3D assembly checked against enclosure.
- [ ] Gerbers and drill files reviewed in an independent viewer.
- [ ] Fabrication notes and stack-up approved by PCB manufacturer.
- [ ] Assembly drawings, pick-and-place and BOM exported.
- [ ] First-article test procedure approved.
- [ ] Independent engineering review signed.
